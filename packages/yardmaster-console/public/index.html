Yardmaster console

The Harness's model list is discovered from [targets.*] in yardmaster.toml (ADR-0028). Enable/disable, Default, and Approve/Reject here write to [harness.overrides.<id>] in the config — they're operator edits, so they apply immediately, same as editing the Config tab by hand and saving. With Require approval for new models on, a model only ever goes live in dsh (or the router's own /v1/models) once you explicitly Approve it — turn it on, then click Approve all currently live once so your existing model list doesn't disappear while you catch up on the rest.
